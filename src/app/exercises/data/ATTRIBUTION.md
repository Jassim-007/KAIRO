# Exercise dataset attribution

This project includes the text and classification catalog from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), retrieved from its `main` branch on 2026-10-19. The upstream project describes the catalog as 800+ exercises and publishes its repository under the Unlicense. See the accompanying `LICENSE.md` and upstream README for source history and special thanks.

Exercise illustrations are displayed from the same upstream repository at `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/`. The upstream license is included here; review upstream provenance and any rights-holder notices before repackaging these media in a commercial release. The app does not download, edit, or rehost the image files.

The catalog is supplied as general exercise information, not medical advice. Exercise names, target muscles, and instructions may be incomplete or inaccurate; users should choose appropriate movements and stop if they experience pain.
